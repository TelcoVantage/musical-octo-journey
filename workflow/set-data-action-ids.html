Set data action IDs

Architect links a workflow to its data actions by ID, and your org gives the two new data actions their IDs when you import them. Paste those IDs here to get a workflow file that imports with nothing left to fix. This page works offline; nothing is sent anywhere.

Where to find an ID
  1. Admin > Integrations > Actions, then open the data action.
  2. The ID is the part of the address bar that starts with custom_-_, for example
    …/integrations/actions/custom_-_eeb9b6e4-05b2-4d0e-95a5-1139ac535f19/setup/contracts
